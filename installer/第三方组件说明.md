# 第三方组件与来源

本候选的 Windows x64 主程序包含 .NET、ASP.NET Core、Windows Desktop 10.0.15；WebView2 SDK 1.0.3537.50；Microsoft.Data.Sqlite 10.0.15 和 SQLitePCLRaw 2.1.13。应用内的宿主使用 Microsoft.AspNetCore.Mvc.Testing / TestHost 10.0.15，属于程序运行所需内容。

随附 NuGet 组件、获取版本、声明的许可及随包原始文本见 [NuGet 组件清单](licenses/NuGet-1.3.1/INDEX.md)。WebView2 SDK 不是完整浏览器运行时。Web 前端使用 react/react-dom 19.3.1、scheduler 0.28.0、lucide-react 1.61.0、mpegts.js 1.8.0、es6-promise 4.2.8；许可保存在 licenses 对应子目录。hls.js 1.5.20 在 wwwroot/lib/hls.min.js.LICENSE.txt 中有版本和来源提示；本源码候选不附该上游包的 Apache-2.0 全文，恢复或分发时应取自对应上游包。

编辑器 WASM 和编解码组件、上游出处和许可见 [编辑器组件许可](licenses/EDITOR-CODEC-NOTICES.md)。这些许可只适用于相应组件，不改变其他组件的许可。

安装器按机器环境和选择另行获取所需组件：Microsoft WebView2 固定运行时、VC++、Gyan FFmpeg、Astral uv/Python 以及 PyPI 的语音与剪映草稿依赖。自包含主程序跳过清单中的备用 .NET 下载。Ollama、PyTorch/Demucs 及模型不包含在本应用归档中；若用户另行启用，则从其提供方/配置的镜像获取。启动向导时的地区判断及安装下载说明见 [安装与卸载](安装与卸载.md)。开源许可、版权和编解码器潜在专利问题不是一回事。
