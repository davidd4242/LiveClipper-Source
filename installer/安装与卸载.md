# LiveClipper 1.3.1：安装、更新与卸载

本包用于支持中的 Windows x64，内含自包含的 .NET/ASP.NET Core/Windows Desktop 10.0.15。程序仍需要 WebView2。安装器未作 Authenticode 签名；请从发布者的 GitHub Releases 或独立确认的备用分享取得，核对 SHA-256 后自行决定是否运行。哈希不是签名。

打开安装向导时，会静默检测当前机器的环境，并以 HTTPS 查询 ipwho.is、失败时查询 api.country.is，按公网 IP 的国家/地区自动选择组件下载源。服务端因此能看到请求 IP；安装器使用国家码。此行为与应用内的手动「检查更新」不同。

开始安装后优先复用已有环境；缺少时准备 WebView2、VC++、FFmpeg、uv、Python 3.11 和语音/草稿组件。语音/草稿环境在这个图形向导中默认启用，不是纯离线安装。VC++ 可能出现 Microsoft 安装程序或 Windows 授权窗口；共享系统组件不会随应用卸载。语音模型在首次转写时另行下载；本机大模型和人声分离不由此向导默认安装。

按地区可能使用清华 PyPI、南京大学 Python 镜像、GitHub 加速站 ghfast.top，或使用 Microsoft、GitHub、PyPI 等官方源；可选模型和工具也可能联系各自来源。带固定摘要的发行文件由安装器校验；Python 软件包走 uv/PyPI，不等于每个转移依赖都在安装器内逐文件固定哈希。

安装前请关闭 LiveClipper。已有安装请核对所选路径、备份重要工程；不要手工删除数据目录来更新。卸载请使用 Windows 已安装的应用或该安装目录内的卸载程序，仔细查看数据保留选项。如需应用更新，在「设置 → 关于」手动检查。程序不会自动运行下载的安装包。
