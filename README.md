# LiveClipper 1.3.1 · 源码版

Windows 桌面直播录制、字幕与剪辑工具。此树基于 1.3.1 发行构建输入整理，**不是原版安装包的逐字节可重建源码**。没有导入早期 Git 历史。官方已发布的程序继续放在 [独立发行仓的 v1.3.1 页面](https://github.com/davidd4242/LiveClipper-Releases/releases/tag/v1.3.1)。

## 本版包含什么

- .NET 桌面外壳、应用接口、领域和直播组件，TypeScript 工作台，Python 工作器、测试源码和 Windows 安装器工程。
- 保留原版更新检查。为保护用户，公开源码版不读取外部浏览器的既有登录状态。旧界面按钮被禁用，兼容接口只返回未检测结果。此差异不改变原版安装程序。
- 六枚旧图标及原品牌标志不在本仓；相同文件名的图形均为此次新绘的中性占位图。未附录屏、设计截图、内部流程核对、开发会话、模型或构建缓存。
- 两组编辑器运行文件不随仓分发。这些文件包含上游衍生 JavaScript 和已嵌入的二进制编码器；保留 [154 项相对路径与 SHA-256](docs/editor-runtime-files.csv)。已有合法取得的官方 1.3.1 安装时，可以按清单在本机复原。此处不提供原版编解码器的完整构建链。
